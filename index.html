Politique de confidentialité

Dernière mise à jour : 26 mars 2026

OpCardex est une application mobile gratuite permettant de gérer sa collection de cartes One Piece TCG. Cette politique explique quelles données sont collectées, comment elles sont utilisées et quels sont vos droits.

1. Responsable du traitement

OpCardex est développée et maintenue par un développeur indépendant français.

2. Données collectées

Sans compte :
Aucune donnée personnelle n'est collectée. Toutes les données (collection, classeurs, scellés) sont stockées uniquement sur l'appareil de l'utilisateur.

Avec un compte (optionnel) :

  • Adresse email — pour l'authentification
  • Données de collection — cartes, classeurs, produits scellés — uniquement si la synchronisation cloud est activée

Aucune collecte de :

  • Données de localisation
  • Contacts, photos ou fichiers personnels
  • Données de navigation ou comportementales
  • Informations de paiement

3. Finalité du traitement

Les données collectées servent uniquement à :

  • Authentifier le compte utilisateur
  • Synchroniser la collection entre plusieurs appareils
  • Permettre la restauration des données en cas de réinstallation

4. Base légale (RGPD)

Le traitement repose sur le consentement explicite de l'utilisateur, formalisé lors de la création du compte ou de l'activation de la synchronisation. Ce consentement peut être retiré à tout moment en supprimant le compte.

5. Hébergement et sous-traitants

Les données cloud sont hébergées par Supabase (infrastructure AWS, région EU West). Supabase agit en qualité de sous-traitant et est soumis à des obligations de confidentialité strictes.

Les images de cartes proviennent de TCGdex, une API publique et gratuite. Aucune donnée personnelle n'est transmise à TCGdex.

6. Durée de conservation

  • Données locales : conservées jusqu'à désinstallation de l'application
  • Données cloud : conservées jusqu'à suppression du compte
  • Emails : supprimés dans les 30 jours suivant la demande de suppression

7. Vos droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants :

  • Accès — obtenir une copie de vos données
  • Rectification — corriger des données inexactes
  • Suppression — effacer votre compte et toutes les données associées
  • Portabilité — récupérer vos données dans un format lisible
  • Opposition — vous opposer à un traitement

Pour exercer ces droits, vous pouvez introduire une réclamation auprès de la CNIL.

8. Publicités (Google AdMob)

L'application affiche des publicités via Google AdMob (bannières et publicités avec récompense). Google peut collecter certaines données techniques anonymes (identifiant publicitaire, type d'appareil, interactions avec les annonces) conformément à la politique de confidentialité de Google.

Les publicités avec récompense sont optionnelles : elles sont uniquement affichées à la demande explicite de l'utilisateur pour obtenir des scans supplémentaires.

9. Mineurs

L'application n'est pas spécifiquement destinée aux enfants de moins de 13 ans. Aucune donnée de mineurs n'est sciemment collectée.

10. Modifications

Cette politique peut être mise à jour. En cas de changement significatif, une notification sera affichée à l'ouverture de l'application. La date de dernière mise à jour est indiquée en haut de cette page.
